# SashimiCloud

Static HTML, CSS and JavaScript website. No install or build step is required.

## Bouldering plan

Open `bouldering.html` for the full 12-week plan. Home and Adventures link to it. The page uses the existing fonts, mountain artwork and sky themes. Tables scroll horizontally on small screens; sections expand and collapse without JavaScript. Print opens all sections, and the original Markdown plan is downloadable.

Added: `bouldering.html`, `training.css`, `training.js`, `training-plan.md`.
Updated: `index.html`, `adventures.html`, `sitemap.xml`.

## Publish

Copy the files from this folder into the root of the existing Sashimicloud-2.0-hp repository, preserving its current deployment configuration. Commit and push through your normal publishing workflow. This archive does not itself update sashimicloud.com.
